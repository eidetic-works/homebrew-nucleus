# homebrew-nucleus

Homebrew tap for [Nucleus MCP](https://github.com/eidetic-works/nucleus-mcp) — Sovereign Agent OS.

## Install

```sh
brew tap eidetic-works/nucleus
brew install nucleus-mcp
```

Then:

```sh
nucleus --version
nucleus init ~/.brain
```

See https://nucleusos.dev for full docs.
